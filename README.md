# tg-assistant

Личный ИИ-ассистент в телеграме на Gemini (через Google-аккаунт и роутер
`zexadev/gemini-web2api-go`). По умолчанию Gemini 4 Argon, рассуждения средние.
Работает в GitHub Actions или на любом сервере (см. «На сервере»).

## Что умеет

- отвечает rich-сообщениями телеги: таблицы, формулы, заголовки, код, сноски,
  с цитатой твоего сообщения
- пока думает, в чате виден черновик с ходом работы. можно остановить кнопкой
- рисует картинки, делает видео (Veo) и музыку (Lyria), глубокие исследования
- читает фото, альбомы, PDF и текстовые файлы
- длинный текст, который телега порезала на несколько сообщений, и всё, что
  написано подряд, считает одним вопросом
- под ответом кнопки с продолжением разговора и «🔁 Ещё раз»
- `/settings` - модель и глубина рассуждений, `/new` - новый диалог

Модели:

- `4 Argon` (`gemini-4-argon`) — сложные задачи (флагман Google Ultra/Advanced)
- `3.1 Pro` (`gemini-3.1-pro`) — расширенные возможности рассуждения
- `3.8 Flash` (`gemini-3.8-flash`) — all-around help, новейший быстрый Flash
- `3.5 Flash-Lite` (`gemini-3.5-flash-lite`) — самые быстрые ответы
- `Gemini Image` (`gemini-image`) — генерация картинок (Nano Banana)
- Уровни рассуждений: Низкий (быстрый), Средний (умеренный), Высокий (глубокий)
- Куки аккаунта автоматически обновляются каждые 10 минут через роутер и
  сохраняются в зашифрованном виде. Для первоначального подключения или смены
  аккаунта достаточно запустить `~/sync_gemini.sh`.

## Настройка

1. Бот у @BotFather, его токен
2. Секреты в Settings -> Secrets and variables -> Actions:

| | |
|---|---|
| `TG_TOKEN` | токен бота |
| `ALLOWED_USERS` | telegram id через запятую (по умолчанию разрешён владелец) |
| `STATE_KEY` | любая длинная строка, ей шифруется история |

3. Actions -> Бот -> Run workflow

Смена длится 5 часов, потом история шифруется, коммитится в `state/` и
запускается следующая смена. Репо публичный (так минуты Actions бесплатные),
поэтому история лежит только в зашифрованном виде.

## На сервере

Без systemd (например, в песочнице Daytona) бот и роутер держит `deploy/run.sh`:

```
git clone https://github.com/hutbobrika-code/tg-assistant.git && cd tg-assistant
printf 'TG_TOKEN=...\nSTATE_KEY=...\nALLOWED_IDS=...\n' > .env
deploy/run.sh start
```

Скрипт один раз расшифровывает историю и сессию Google из `state/`, потом
поднимает роутер и бота и перезапускает их, если упадут. Логи — в `logs/`.
`deploy/run.sh status` и `deploy/run.sh stop` — проверить и остановить.
Не запускайте бота одновременно здесь и в Actions: Telegram отдаёт сообщения
только одной копии.

## Локально

```
python3 -m unittest
TG_TOKEN=... ALLOWED_USERS=... python3 bot.py
```

Для схем нужен `rsvg-convert` (пакет librsvg2-bin).
