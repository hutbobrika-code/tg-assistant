# tg-assistant

Личный ИИ-ассистент в телеграме на бесплатных моделях OpenCode Zen. По умолчанию
Muse Spark 1.3 в режиме xhigh. Работает в GitHub Actions, сервер не нужен.

## Что умеет

- отвечает rich-сообщениями телеги: таблицы, формулы, заголовки, код, сноски
- пока думает, в чате виден черновик с текущим шагом рассуждений, можно
  остановить. в готовом ответе ход мыслей свёрнут в блок «💭 Думал N с»
- читает фото, альбомы, PDF и текстовые файлы
- рисует схемы: модель пишет svg, бот превращает его в картинку
- под ответом кнопки с продолжением разговора и «🔄 Заново»
- `/model` - выбор модели и режима размышлений (от ⚡ мгновенно до 🔴 максимум)
- `/new` - новый диалог

Модели (все бесплатные):

| модель | фото | PDF | режимы |
|---|---|---|---|
| Muse Spark 1.3 | да | да | minimal - xhigh |
| Space Bunny | да | | low - max |
| MiMo V2.6 Flash | да | | |
| Ling 3.0 Flash | | | low - high |
| Nemotron 3 Ultra | | | |
| Big Pickle | | | |

Muse Spark 1.3 бесплатна в обмен на то, что Meta может учить модели на
переписке. Личное туда лучше не писать.

## Настройка

1. Бот у @BotFather, его токен
2. Ключ OpenCode Zen: https://opencode.ai/auth
3. Секреты в Settings -> Secrets and variables -> Actions:

| | |
|---|---|
| `TG_TOKEN` | токен бота |
| `ALLOWED_USERS` | telegram id через запятую, остальным бот не отвечает (свой id бот напишет, если написать ему) |
| `OPENCODE_API_KEY` | ключ OpenCode Zen |
| `STATE_KEY` | любая длинная строка, ей шифруется история. без неё история живёт до конца смены |

4. Actions -> Бот -> Run workflow

Смена длится 5 часов, потом история шифруется, коммитится в `state/` и
запускается следующая смена. Репо публичный (так минуты Actions бесплатные),
поэтому история лежит только в зашифрованном виде.

## Локально

```
python3 -m unittest
TG_TOKEN=... OPENCODE_API_KEY=... ALLOWED_USERS=... python3 bot.py
```

Для схем нужен `rsvg-convert` (пакет librsvg2-bin).
