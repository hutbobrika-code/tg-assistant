# tg-assistant

Личный ИИ-ассистент в телеграме на бесплатных моделях OpenCode Zen. По умолчанию
Muse Spark 1.3 в режиме xhigh. Работает в GitHub Actions, сервер не нужен.

## Что умеет

- отвечает rich-сообщениями телеги: таблицы, формулы, заголовки, код, сноски,
  с цитатой твоего сообщения
- пока думает, в чате виден черновик: текущий шаг рассуждений, что ищет в
  интернете, какую страницу читает. можно остановить кнопкой. в готовом ответе
  ход мыслей и список источников свёрнуты в блоки
- сам ищет в интернете, когда нужны свежие данные (поиск через публичный
  mcp-сервер Exa, ключ не нужен), может вставить в ответ картинки со страниц.
  битые ссылки на картинки бот выкидывает до отправки
- читает фото, альбомы, PDF и текстовые файлы
- рисует схемы: модель пишет svg, бот превращает его в картинку
- длинный текст, который телега порезала на несколько сообщений, и всё, что
  написано подряд, считает одним вопросом
- под ответом кнопки с продолжением разговора и «🔄 Заново»
- `/model` - модель, режим размышлений (от ⚡ мгновенно до 🔴 максимум), интернет
- `/new` - новый диалог

Модели:

- **Gemini (через Google аккаунт)**:
  - `4 Argon` (`gemini-4-argon`) — сложные задачи (флагман Google Ultra/Advanced)
  - `3.1 Pro` (`gemini-3.1-pro`) — расширенные возможности рассуждения
  - `3.8 Flash` (`gemini-3.8-flash`) — all-around help, новейший быстрый Flash
  - `3.5 Flash-Lite` (`gemini-3.5-flash-lite`) — самые быстрые ответы
  - `Gemini Image` (`gemini-image`) — генерация картинок (Nano Banana)
  - Уровни рассуждений: Низкий (быстрый), Средний (умеренный), Высокий (глубокий)
  - Куки аккаунта автоматически обновляются каждые 10 минут внутри GitHub Actions роутера (`zexadev/gemini-web2api-go`) и сохраняются в зашифрованном виде. Для первоначального подключения или смены аккаунта достаточно запустить `~/sync_gemini.sh`.

- **Бесплатные модели OpenCode Zen**:
  - `Muse Spark 1.3`, `Space Bunny`, `MiMo V2.6 Flash`, `Ling 3.0 Flash`, `Nemotron 3 Ultra`, `Big Pickle`

## Настройка

1. Бот у @BotFather, его токен
2. Секреты в Settings -> Secrets and variables -> Actions:

| | |
|---|---|
| `TG_TOKEN` | токен бота |
| `ALLOWED_USERS` | telegram id через запятую (по умолчанию разрешён владелец) |
| `STATE_KEY` | любая длинная строка, ей шифруется история |

3. Actions -> Бот -> Run workflow

Смена длится 5 часов, потом история шифруется, коммитится в `state/` и
запускается следующая смена. Репо публичный (так минуты Actions бесплатные),
поэтому история лежит только в зашифрованном виде.

## Локально

```
python3 -m unittest
TG_TOKEN=... OPENCODE_API_KEY=... ALLOWED_USERS=... python3 bot.py
```

Для схем нужен `rsvg-convert` (пакет librsvg2-bin).
